# ISSMHelperFunctions

MATLAB helper library for [AntarcticIceMeltFracture](https://github.com/jaspercjp/AntarcticIceMeltFracture).

- `+ISSMParamUtils/` — model parametrizations and boundary conditions (flat/constant-slope bed, MISMIP).
- `+ISSMSteadyStateUtils/` — steady-state spin-up, mesh refinement and relaxation.
- `+ISSMModelUtils/` — melt and calving experiments, transect extraction.
- `+ISSMStressUtils/` — stress extraction (points, transects, width integrals).
- `+ISSMGLUtils/` — grounding-line flux.
- `+ISSMAreaUtils/` — floating area.
- `+ISSMMeshUtils/` — mesh copying and AMR utilities.
- `+ISSMMiscUtils/` — saving, thinning and file utilities.
- `+ISSMPlotUtils/` — plots and animations.
- `PyHelpers/` — Python readers and plotting for ISSM output.
